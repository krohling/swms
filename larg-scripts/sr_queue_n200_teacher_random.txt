# Eval queue for larg-scripts/launch_sr_queue.sh, in priority order. It takes over
# from sr_queue_n200_teacher.txt: the same jobs in the same order (finished and
# claimed ones are passed over), plus the teacher's matched random-pick control
# (Kevin 2026-11-17). A worker launched before the "random" job kind existed
# stops on a line it does not know, so that file stays as it is and this one is
# for workers started from a launcher that knows the kind.

# 4. Qwen teacher (zero-shot judge picks among k=8 proposals), 200 episodes per
#    task on the seeds of step 3 (6000-6049 + 6100-6249), once step 3 has run out.
# 5. Matched control for step 4: the same proposals and rollouts, the executed
#    one drawn at random, no Qwen; the same 200 seeds per task.
# 6. exp6a from n=50 to n=200 per task (Kevin 2026-11-17: 200 per task is the
#    protocol from here on): 150 more episodes per checkpoint on the seeds of
#    step 3 (6100-6249), latest checkpoint first, after step 5. A checkpoint
#    that is not on LARG yet is passed over until it is.
# 7. exp5b 8k grid at n=200 per task (Kevin 2026-11-17), last in the queue,
#    latest checkpoint first. The checkpoints are the LARG copy's (run
#    exp5b-ogbblend-b96-larg, training on debruyne): in swms-exp5,
#    outputs_swm_lora/exp5b_full is a symlink to exp5b_full_larg, so each one is
#    picked up when the training run writes it.
# 8. The released SWM checkpoint (jacob3333/paligemma_wm_ogbench) under the
#    authors' own eval, 200 episodes per task on the seeds of step 3 (Kevin
#    2026-11-17: the ceiling row; the paper measured it at n=50), at the very
#    end. Four 50-episode jobs per task; the three on the paper's seeds
#    (6000-6049) come first. A worker started from a launcher older than
#    eff4a21 does not know the swm kind and stops on these lines.
# 9. Diagnostic, not a results row (Kevin 2026-11-18): exp6a 56k with the
#    per-cycle log on (the pick, the scores, and the simulator outcome of all
#    8 proposals), 50 episodes per task on seeds 6000-6049, behind everything
#    above. Run name exp6acyc is an alias: in swms-exp6cyc (branch
#    exp6-cycle-log), outputs_swm_lora/exp6acyc_full is a symlink to
#    swms-exp6's exp6a_full and train_exp6acyc.yaml turns the log on, so the
#    results land in experiments/exp6acyc_larg, apart from exp6a's rows.
